# Hotel Ritam - Luxury Hotel Website

A full-fledged, modern hotel website built with Next.js, TypeScript, and Tailwind CSS. This comprehensive hotel booking system showcases luxury accommodations with a beautiful, responsive design and intuitive user experience.

## 🌟 Features

### Core Features
- **Modern Hero Section** with booking form integration
- **Room & Suite Showcase** with detailed information and image galleries
- **Comprehensive Amenities Display** with interactive icons
- **Guest Testimonials & Reviews** with rating system
- **Responsive Design** optimized for all devices
- **Search & Filtering System** for room selection
- **Interactive UI Components** with smooth animations

### Technical Features
- **Next.js 15** with App Router
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **React Hook Form** for form handling
- **Zod** for validation
- **Lucide React** for icons
- **Hot Toast** for notifications

### Pages & Sections
- **Homepage** with hero, featured rooms, amenities, and testimonials
- **Rooms Page** with advanced filtering and search
- **Responsive Header** with navigation and contact info
- **Comprehensive Footer** with links and contact information

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm, yarn, pnpm, or bun

### Installation

1. **Clone or navigate to the project:**
   ```bash
   cd "Hotel Ritam"
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
npm start
```
